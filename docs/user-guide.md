# User Guide — TGX Waste Coin Platform
> PT Jwalita Energi Trenggalek | Sprint 26

## Untuk Siswa (Students)

### 1. Daftar & Login
- Buka aplikasi TGX di browser atau smartphone
- Daftar dengan email sekolah
- Login menggunakan email & password

### 2. Setor Sampah
1. Klik **Setor Sampah**
2. Pilih jenis sampah (Plastik, Kertas, Kardus, dll.)
3. Timbang dan masukkan berat (kg)
4. Foto sampah (opsional — membantu AI verification)
5. Submit → tunggu verifikasi petugas

### 3. Terima TGX Coin
- Setelah disetujui, TGX Coin otomatis masuk ke **Wallet**
- Cek riwayat di **Dompet → Riwayat Transaksi**

### 4. Tukar Reward di Marketplace
1. Buka **Marketplace**
2. Pilih reward (Bibit Pohon, Tas TGX, Voucher, dll.)
3. Klik **Tukar** — coin langsung terpotong
4. Catat **Kode Klaim** untuk pengambilan reward

### 5. Level & Achievement
- Kumpulkan sampah → naik level otomatis
- Raih badge: 🌱 First Deposit, ♻️ Plastic Hero, 🏆 Eco Champion
- Cek **Leaderboard** — bersaing dengan teman dan sekolah lain

---

## Untuk Operator Sekolah

### Verifikasi Setoran
1. Login sebagai Operator Sekolah
2. Buka **Dashboard → Verifikasi Sampah**
3. Cek foto dan berat setoran siswa
4. Approve atau Reject dengan catatan

### Monitor Progress Sekolah
- Dashboard menampilkan: total sampah bulan ini, coin beredar, ranking sekolah
- Export laporan dalam format Excel/PDF

## Aplikasi Mobile

Unduh **TGX Mobile** (React Native Expo):
- Scan QR Code setoran sampah
- Lacak lokasi operator lapangan (GPS)
- Sync otomatis saat offline → online
- Tersedia untuk Android & iOS

## FAQ

**Q: Berapa TGX Coin yang saya dapat per kg sampah?**
A: Setiap jenis sampah memiliki nilai berbeda. Plastik = 10 coin/kg, Kertas = 5 coin/kg.

**Q: Reward sudah ditukar tapi belum diterima?**
A: Tunjukkan **Kode Klaim** ke petugas di titik pengambilan yang tertera.

**Q: Coin saya berkurang tanpa tukar reward?**
A: Tidak mungkin — semua transaksi coin dicatat di Riwayat Wallet. Hubungi admin jika ada kejanggalan.

**Q: Bagaimana cara naik level?**
A: Level naik otomatis berdasarkan total berat sampah yang berhasil diverifikasi.
